This is a hidden QA / dry-run session.

It mirrors the three polls from the real Agentic VC Dojo Launch Session at
identical prompts/options/types but with separate poll IDs in the database, so
test votes here don't touch production tallies. This page is reachable only
via its direct URL and never appears on the public `/sessions/` listing.

Use the same `pnpm set-poll-status --remote` and (eventually) `pnpm sync:session --remote`
commands to flip these polls — just point at the QA poll IDs:

- `poll_qa_participation-mode`
- `poll_qa_ai-use-cases`
- `poll_qa_nerdy-scale`

When you're done testing, run `pnpm wipe:test-session` (if/when we add it) or
manually delete the `sess_2026-04-29-polls-qa` rows via Turso shell.
