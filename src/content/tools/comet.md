Comet is Perplexity's answer to the question "what if the browser itself were the agent." It's Chromium underneath, so every site works the way you expect, with an assistant that can see the current page and — crucially — **act inside the sessions you're already authenticated into**. That's the capability that separates this category from a chat window: it isn't reasoning about a description of your inbox, it's operating your inbox.

For the Dojo the relevant fact is availability. Comet went free across macOS, Windows, iOS and Android in October 2025, which makes it the lowest-friction way to feel what an agent-native browser actually does. It's the recommended starting point in [[guides/agent-native-browsers/index|Orientation: Agent-Native Browsers]] for that reason — not because it wins on any one axis, but because you can install it this afternoon on the machine you already have.

Comet is also the browser with the most public security scrutiny, which is worth knowing rather than avoiding: Brave's security team published a working indirect prompt-injection attack against it in 2025, and the underlying problem is structural to the category rather than specific to Perplexity. Run it in a dedicated browser profile with only the logins a task needs.
