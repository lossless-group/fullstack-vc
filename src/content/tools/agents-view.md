A local-first inspector for AI agent sessions — surfaces what the agent did, what tools it called, and what it returned, without sending the trace off your machine. The local-first posture matters in venture contexts where agent traces would otherwise contain dealflow, LP, or portfolio data that can't leave the device.

Pairs naturally with: [[OpenClaw]], [[Hermes-Agent]], [[Claude-Code]], and any locally-run agent stack where you want post-hoc visibility into what the agent actually did.
