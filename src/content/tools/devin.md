The hosted end of the coding-agent spectrum: where [[tools/claude-code|Claude Code]] and [[tools/pi-dev|Pi]] run on your machine, Devin runs in Cognition's cloud and hands back finished pull requests.

One Dojo member keeps Devin's IDE open purely as a viewer, to read what agents produced and leave comments, while doing the actual work in Claude Code. That split (one tool to do, another to inspect) is a pattern worth copying whatever the tools are.
