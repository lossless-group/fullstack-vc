Perplexity answers questions by searching the live web and citing every source, which makes it a fast first pass on a company, a market or a person.

## Why VCs care

- **Licensed data in the same search box.** PitchBook Essentials (funding history, investors, leadership), CB Insights (market maps) and Statista (market sizes) come with every plan, up to a monthly premium-query limit. Type `@PitchBook` to aim a question at one.
- **Your own subscriptions, connected.** Licensed connectors link Crunchbase, FactSet, Guidepoint, Quartr, AngelList, Papermark and others, so Perplexity can answer from data you already pay for. These need Pro, Max or Enterprise plus your license with the partner.
- **Inside your agent.** The Computer MCP server (`https://www.perplexity.ai/rest/computer/mcp`) plugs Perplexity, premium sources included, into Claude Code, Claude Desktop and other MCP clients. It signs in as you and spends your account's credits.
- **For builders.** The API offers ranked web search (up to five queries per request), monitors that rerun a search or watch pages on a schedule and return only what's new, and an Agent API that runs models with web search. The API can't reach the premium sources.

> [!warning] Licensed data isn't yours to publish
> Premium answers come under the provider's terms or your own agreement with the partner. They're usually fine in an internal memo, but check before anything reaches LPs or the public.
