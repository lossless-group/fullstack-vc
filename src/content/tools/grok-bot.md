Where [[tools/instinct|Instinct]] and [[tools/muse|Muse]] give you one assistant, Grok Bot gives you a staff: several bots, each on its own machine, each running a long-lived project.

**What Dojo members report.** One member runs threaded projects (a home renovation, a nonprofit) as separate Grok bots, with a "chief of staff" bot on top — which, so far, can't actually manage the others. A money-making experiment didn't work out. Others are drawn to it because it acts on its own initiative, which agents like [[tools/openclaw|OpenClaw]] don't.

The lesson that keeps recurring: many agents with no shared memory is its own problem. That's the argument for a home connector that every agent reads and writes — see [[guides/home-connector-on-cloudflare-artifacts/index|Build a Home Connector on Cloudflare Artifacts]].
