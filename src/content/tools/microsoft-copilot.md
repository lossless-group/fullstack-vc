Microsoft Copilot spans several distinct surfaces — the consumer chat assistant at copilot.microsoft.com, Microsoft 365 Copilot for Word/Excel/Outlook/Teams, GitHub Copilot for code completion and chat, and Copilot in Windows. All share the Copilot brand but have different licensing, data boundaries, and feature sets.
