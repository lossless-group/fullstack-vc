The stability-first choice for a Linux dev machine: if an update breaks something, you roll back to the last working configuration. A Dojo member moved to NixOS with [[tools/hyprland|Hyprland]] after an [[tools/arch-linux|Arch]] install broke from going a month without updates. Pairs well with agents, which can edit the config file for you. Compare [[tools/omarchy|Omarchy]], the opinionated Arch route.
