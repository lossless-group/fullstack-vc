For agent users, Playwright is the dependable way to give [[tools/claude-code|Claude Code]] hands in a browser. Dojo members reach for it when [[tools/claude-in-chrome|Claude in Chrome]] won't connect, and some add it to every project so agents can test their own UI work and run browser errands.

It drives a fresh browser rather than your logged-in one, which is the main difference from agent-native browsers like [[tools/comet|Comet]] or [[tools/aside|Aside]]. See also [[tools/chrome-devtools-mcp|Chrome DevTools MCP]].
