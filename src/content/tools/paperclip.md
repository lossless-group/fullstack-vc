Paperclip is an open-source control plane for teams that coordinate AI agents across shared work, with tasks, ownership, review, budgets, governance, and agent orchestration in one workspace. [^hg8pbs] The operating company is Paperclip Labs, Inc. [^u7c98l]

A user testimonial on its homepage sums it up: "OpenClaw is an employee, Paperclip is the company." [^hg8pbs] Paperclip's own comparison page makes the same case. [^q7evcz] You don't prompt an AI. You run a team of them, approve what they do, and set what they can spend.

## Value Proposition & Features

Paperclip targets AI-native organizations that want humans to retain control while agents execute work across engineering and other business functions. [^hg8pbs] Its core pitch is a shared, self-hosted workspace rather than a single-agent coding interface. [^hg8pbs]

- **Organization and roles:** Provides an org chart with agent titles, reporting lines, roles, and job descriptions. [^hg8pbs]
- **Goal alignment:** Links tasks to organizational goals so agents have explicit context for what they should accomplish and why. [^hg8pbs]
- **Task and ticket management:** Assigns work to agents, tracks conversations and decisions, and maintains activity history. [^hg8pbs]
- **Multi-agent orchestration:** Supports agents including Claude Code, Codex, Gemini CLI, Cursor, OpenCode, Hermes, HTTP agents, and other adapters. [^u7c98l] [^ijobs7]
- **Governance and approvals:** Lets people approve work, override strategy, pause agents, or terminate them. [^hg8pbs]
- **Budgets and controls:** Applies company-, agent-, and project-level spending limits, with automatic pausing at the hard limit. [^ehmyg8]
- **Auditability:** Provides tool-call tracing, ticket histories, and audit logs. [^hg8pbs]
- **Deployment flexibility:** Runs locally or on a self-hosted server; Paperclip Cloud is described as waitlist-only. [^u7c98l]

## Why VCs care

A firm's agent stack tends to grow one agent at a time: a dealflow agent, a memo agent, a portfolio-monitoring agent, each with its own keys and its own bill. Paperclip puts them in one org chart, with budgets per agent and a person approving the work, the same way you'd run a small team.

## Product Roadmap / Announcements

As of November 27, 2026:

- **November 25, 2026:** Paperclip's published product material describes Paperclip Cloud as having a waitlist rather than general availability. [^u7c98l]
- **November 25, 2026:** A native desktop application remains on the roadmap, while the current product is a responsive web application. [^ehmyg8]
- **November 25, 2026:** "Bring-your-own-ticket-system" is listed as a roadmap item. [^hg8pbs]

## Who it's for, who it's not for

Paperclip is designed for teams running multiple agents, especially coding agents, who need shared tasks, ownership, review stages, audit trails, budgets, and organizational structure. [^u7c98l] [^ehmyg8] It can also coordinate work in support, marketing, and operations rather than limiting use to software development. [^qpc2c2]

It is not the best fit for someone seeking only a personal coding-agent IDE, a native desktop application today, or a hosted product with established public pricing. [^ijobs7] [^ehmyg8]
