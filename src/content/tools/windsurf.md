As of July 14, 2025, Windsurf was acquired by Cognition AI, makers of code-specific trained AI models.

### Cascade

Windsurf's Cascade agent supports memories and project rules. Prompt with "create a memory of …" to persist context across sessions. Project rules live in `.windsurfrules` at the repo root; Codeium maintains a [public rules directory](https://codeium.com/windsurf/directory) with examples.
