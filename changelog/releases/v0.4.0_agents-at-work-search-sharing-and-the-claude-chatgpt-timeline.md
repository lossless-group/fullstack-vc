# v0.4.0 — Agents at Work

## Why Care?

v0.3.0 made the hub's long-form content readable. This release makes it *findable* and *shareable*, then fills it with the material for the November 19 all-hands, "Agents at Work."

Before, finding a tool meant scrolling a catalogue, a shared link unfurled as a generic site card, and a name in a write-up was just a name. Now the whole hub is searchable, every page and every section shares as its own card, every heading is a link you can send, and hovering a fellow's name shows who they are. On top of that: a sourced six-month timeline of Claude and ChatGPT, two new playbooks, and a 26-slide deck built as a web page.

## What's New?

### Find, share, link

- **Search the whole hub.** A search palette with stackable tag filters covers tools, recipes, sessions, people, projects, working groups and now the timeline.
- **41 new tools from the Dojo chat,** with every fellow's stack updated from what they said they use. Since then: Dots, Claude Duet, Axel, lossless.at, Context Vigilance, DidiDecks AI and MemoPop AI.
- **Every page and every section shares with its own card.** Send a hub link in iMessage or WhatsApp and it unfurls as that page's card; share a section and you get that section's card.
- **Every heading is a link you can send,** and whatever you send carries the heading's name.
- **Hover a name, meet the person.** People and tools in write-ups open a card on hover: photo, firm, role, what they use.
- **Tool carousels in any post** with `:::tool-showcase`, and a brighter purple for links.
- **The header folds into its menu button below 1080px,** so search no longer collides with the nav. Changelog and Timeline now live under More.

### The content for Agents at Work

- **[Six months of Claude and ChatGPT](/timelines/claude-and-chatgpt).** 68 releases from May 18 to November 18, 2026, Anthropic and OpenAI side by side, each checked against the company's own page and linked to it.
  - Filter by track, show headlines only, or flip to newest first.
  - A boxed "where things stood going in" section explains what launched before May.
- **[How to Use Claude & GPT like an Agent-Native VC Going into 2027](/guides/agent-native-vc-2027/).** Eight habits, from using Claude Code and Codex instead of the chat window, through briefs, scheduled routines, HTML artifacts, enterprise context, direct API and browser access and personal agents, to a firm-wide home connector.
- **[One Home Connector for Your Whole Team](/guides/one-home-connector/).**
  - It opens with a prompt you paste into Claude Code or Codex.
  - It explains why one connector should hold a firm's skills, context, memory and tools, which three firms already run on one, and why Cloudflare Artifacts makes it cheap.
- **[The Nov 19 deck](/slides/2026-11-19_monthly-all-hands).** A web page with month-by-month takeaways ("Now you can…"), discussion slides for personal agents, and five steps to a first home connector.
- **[Takeaways from Using Personal Agents](/guides/personal-agents-in-the-dojo/),** distilled from the group chat, with every person linked to their profile.
- **A new setup guide** (October): turning a new Mac into an agent-native dev machine.

### Fixed

- **"Make my profile public" works again.** The switch had silently done nothing since May; flipping it now puts you on the people page on the next load.

## Under the Hood

- **Share images are cached by content.** Pages that haven't changed don't re-render their cards, which kept builds fast as every section gained a card.
- **Hover cards ride in a `<template>`.** A card's markup inside a paragraph would split the sentence, so each link carries its card in a template and one popover per page clones it.
- **Search is built from explicit records,** because sessions and people render on demand and there's no complete set of built HTML to crawl.
- **One timeline file feeds the page, the deck and search,** so the three can't disagree. Releases from before the window carry a `prior` flag and stay out of the counts.
- **context-v housekeeping (October):** every doc declares its type and carries the shared metadata template, so the folder reads as an Open Knowledge Format bundle.
