## Why Care?

A skill is a fund's playbook written once for an agent: how we size a market, prep a conference, log a founder call. We've written dozens across our repositories, and nobody outside could see which ones matter to a VC. Now there's one page that lists them, says what each is for, and gives a one-click prompt to load any of them. Alongside it, a guide to mods, the newest way to change Claude Code itself.

## What's New?

- **[The VC Agent Skill Pack](/guides/vc-agent-skill-pack/).** Thirty-five open skills, each a card with what it does, what to use it for, a link to it on GitHub and a **Copy the prompt** button.
  - **Three products roll skills up:** MemoPop (research and memos), DidiDecks (decks) and event-hog (events). Each gets a section led by its own card, and each skill in it says "Part of MemoPop", "Part of DidiDecks" or "Part of event-hog".
  - The rest are grouped as CRM and contacts, brand and site, back office, and team context.
  - **Skills don't show up on their own:** a section on why a downloaded pack stays invisible to an agent, and the fixes: a symlink per skill, GNU Stow for the whole pack, or hosting skills behind a home connector.
- **[Mods: Make Claude Code Work the Way Your Fund Does](/guides/claude-code-mods/).** What a mod is, where mods run (yes in Claude Desktop's Code tab; not in the chat or Cowork tabs), why a fund would want one, how to ask Claude for one, how to share it, and why to trust it like software.
- **Skills in any post.** Two new pieces of Lossless Flavored Markdown:
  - `:::skill-pack` (or `:::agent-skills`) turns a list of skill names into a grid of cards; `{suite="memopop-ai"}` lists everything a product rolls up.
  - `:skill[market-capture-analysis]` is an inline link to one skill, with its summary on hover.

## Under the Hood

- **One registry.** `src/data/agent-skills.json` holds every skill the site can show, with the repository and path it lives at, so skills from `lossless-agent-skills`, `memopop-ai`, `investment-memo-orchestrator`, `dididecks-ai` and `event-hog-mcp` sit side by side, and the site still deploys on its own.
- **Duplicates point to the newest copy.** Several skills exist in more than one repository; memopop-ai's copies of the three diligence skills date from June, the main ones from August, so the cards link to the main ones.
- **Both components are on /design-system,** as every new component is.
