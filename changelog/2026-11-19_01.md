## Why Care?

Most VCs still use Claude and ChatGPT as a chat box. The tools moved on: they work on folders of files, run for hours, keep going after you close the laptop, and make decks, dashboards and videos. Today's all-hands is about closing that gap, and these two recipes are the take-home.

## What's New?

- **[How to Use Claude & GPT like an Agent-Native VC Going into 2027](/guides/agent-native-vc-2027/).** Eight habits:
  1. Use Claude Code and Codex, not just the chat window
  2. Write specs, plans and briefs instead of prompts
  3. Put routine work on a schedule (Workspace agents, Cowork, Dots)
  4. Let models work in HTML, CSS and JavaScript, which you never need to learn, with a table of which Claude or ChatGPT artifact fits each job
  5. Experiment with enterprise context: memory startups, enterprise search, vector databases, Graphify and Archify
  6. Give your AI direct API access
  7. Automate your personal life
  8. Create your firm's home connector
- **[One Home Connector for Your Whole Team](/guides/one-home-connector/).** It opens with a prompt you paste into Claude Code or Codex. Then the why: a connector per tool, one account per connector, and no context about which tool is for what. One connector, with the firm's skills, context, memory and tools behind it. We run it for three firms today. It needs a version-controlled store; Cloudflare Artifacts makes that easy, cheap and invisible. We recommend our `-v` folder names.
- **New tools:** [Dots](/tools/dots), [lossless.at](/tools/lossless-at) and [Context Vigilance](/tools/context-vigilance), with tool cards in both recipes.
- **The session page and deck.** Segment 3 is now a short pitch on the session page and five slides in the deck, both pointing to the recipe.
- **The timeline** gains Claude Motion as its own entry (Oct 8), nested sessions in the desktop Code tab (Oct 15), and Anthropic's dreaming: Dreams for Managed Agents (May 6, as context) and the Nov 6 research post.
- **Navigation.** Changelog moved into the More menu, under Timeline. The header now folds into the menu button below 1080px, so the search box no longer collides with the nav.
