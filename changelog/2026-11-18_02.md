## Why Care?

A recipe that talks about five tools used to mean five links you had to open one by one. Now the tools can sit right in the post as cards you swipe through, each showing how many members use it.

## What's New?

- **`:::tool-showcase` works on this site.** It uses the same syntax as lossless.group: a list of `[[tools/…]]` links between `:::tool-showcase` and `:::`. It renders the registry's tool cards in a scroll-snap row with previous/next buttons, and each card carries the "N members using" count from the Stacks page.
- **Lighter, brighter links in posts.** Light mode uses a brighter violet over a lavender underline. Dark and vibrant modes use lavender text, which is also easier to read there. Both are new theme tokens, listed on the brand kit.
- **Tomorrow's session names what shipped.** The Agents at Work page now lists the Claude and ChatGPT updates since July, each with one use for a fund, checked against Anthropic's and OpenAI's own release notes.
- **Dove** joins the registry: an AI email client that merges your accounts into one inbox.

## Under the Hood

The showcase collects the tool links the wikilink plugin produces (`/tools/<handle>`), looks each one up in the tools collection, and skips any it can't find, so a typo drops a card rather than breaking the page. Cards inside a post inherited the prose list spacing, so the component resets it to keep them identical to the catalogue.

LFM moves from 0.6.0 to 0.8.0. The 0.7 and 0.8 releases are additive and opt-in, so rendering doesn't change. Because 0.8.0 was published today, pnpm's minimum-release-age rule needed an explicit exception in `pnpm-workspace.yaml`.

On contrast: the light-mode link violet is about 3.2:1 on the cream background, a deliberate trade for a lighter look on pages where links are mostly names and tool names.
